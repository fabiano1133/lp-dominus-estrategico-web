# Imagem do Hero (homem com MacBook)

Para exibir **homem em pé com MacBook, sem fundo**, no Hero da página:

1. Baixe uma imagem em **PNG com fundo transparente** (ex.: "man holding laptop transparent PNG" em sites como [Pngtree](https://pngtree.com), [Vecteezy](https://www.vecteezy.com/free-png/man-with-laptop) ou [CleanPNG](https://www.cleanpng.com/free/man-with-laptop.html)).

2. Salve o arquivo como **`hero-person.png`** nesta pasta (`public/`).

3. A imagem será exibida à direita do Hero, alinhada pela base (pés no “chão”), sem caixa ou fundo — o fundo escuro da página aparece onde o PNG é transparente.

**Recomendações:**
- Resolução: por volta de 800–1200px de altura.
- Formato: PNG com canal alpha (transparência).
- Assunto: pessoa em pé segurando notebook/MacBook.

Se o arquivo `hero-person.png` não existir, o site usa automaticamente uma imagem de fallback (com fundo).
